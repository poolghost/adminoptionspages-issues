# Security policy

## Reporting a vulnerability

Please **do not** report a security issue in a public issue, in the support forum or anywhere else in public.

Report it privately through GitHub: [report a vulnerability](https://github.com/poolghost/adminoptionspages-issues/security/advisories/new). Only the maintainer can see the report.

Please include:

- the version of Admin Options Pages (and Admin Options Pages Pro, if active)
- what an attacker can do, and which user role they need
- the steps or a proof of concept to reproduce it

You get a reply as soon as possible. When the issue is confirmed, a fix is released first, and the issue is made public after that, with credit to you if you want.

## Supported versions

Security fixes are released for the latest version of Admin Options Pages only.
