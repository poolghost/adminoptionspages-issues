# Admin Options Pages: issue tracker

[Admin Options Pages](https://wordpress.org/plugins/admin-options-pages/) is a beautifully designed WordPress plugin, which makes it incredibly easy to create options menus, pages and fields.

This is where you report bugs and suggest improvements.

The source code of the plugin is not in this repository. It is only used for issues.

## Where to go

| You want to… | Go to |
| --- | --- |
| Report a bug | [Open a bug report](https://github.com/poolghost/adminoptionspages-issues/issues/new?template=bug_report.yml) |
| Suggest a feature or improvement | [Open a feature request](https://github.com/poolghost/adminoptionspages-issues/issues/new?template=feature_request.yml) |
| Ask how to do something | [WordPress.org support forum](https://wordpress.org/support/plugin/admin-options-pages/) |
| Report a security issue | **Not here.** See the [security policy](SECURITY.md). |

Before you open an issue, please search the [open and closed issues](https://github.com/poolghost/adminoptionspages-issues/issues?q=is%3Aissue) and check that you use the latest version of the plugin.

## Supported versions

Admin Options Pages 1.x requires **PHP 8.1** or higher and **WordPress 6.9** or higher. Bugs are fixed in the latest version only.
